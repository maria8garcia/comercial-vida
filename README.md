# Comercial Vida – Proyecto de Base de Datos

Empresa de repuestos automotrices. Flujo del proyecto:
Base transaccional MySQL → ETL (Python/Pandas) → Data Warehouse (modelo estrella) → Dashboard en Power BI.
Además: comparación PySpark vs MySQL y prueba con MongoDB (NoSQL).

## Contenido
- script de la base de datos
- 02→ procedimientos, funciones, triggers, transacciones, auditoría y excepciones
- 03→ roles, copias de seguridad, recuperación e índices
- 04→ MongoDB, archivo JSON, CRUD y comparación SQL vs NoSQL
- 05→ Data Warehouse, tabla de hechos, dimensiones y ETL en Python
- 06→ dashboard en Power BI, KPIs y operación OLAP
- 07 → notebook PySpark y Ventas.csv
- docs → informe y diagramas
